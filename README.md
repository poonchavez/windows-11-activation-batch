# Activating Windows 11 or 10 using Batch File

This very short article is an tutorial of how to activating Windows 11 or Windows 10 without Product Key or Activation Key by using Batch File. 

To activating Windows 11 or Windows 10 using Batch File, just simple copy the code on "activation-batch.txt" and save it as cmd file. Then run the cmd as Administrator. Finally, wait for few minutes and then your Windows 11 has been activated!
